# Product Vision

## Product
Orienteering Training & Analysis Platform

## Purpose
A personal training system for orienteering that turns geographic data into usable training maps and courses, records outdoor sessions, replays movement, and provides actionable navigation/performance analysis.

## Target user
An orienteering athlete training with a smartphone and wanting measurable improvement.

## Core promise
**Choose a map → start a difficult course → navigate → finish → replay → understand mistakes → improve.**

## What the product is not
- Not a generic running tracker.
- Not a social network.
- Not a full professional cartography replacement.
- Not an automatic guarantee of IOF competition-map compliance.
- Not a dashboard-first SaaS product.

## Product principles
- Map-first
- Athlete-first
- Minimal cognitive load
- Actionable feedback
- Reproducible courses
- Honest uncertainty
- Offline-aware
- Mobile-first

## Success criteria
An athlete can start a session without technical knowledge, complete a 10-control course, review the exact route afterward, identify difficult legs, and compare performance across sessions.
