# Product Requirements

## MVP
### Map
- Create/select a training area.
- Display a training map.
- Support pan/zoom/current position.
- Support map orientation and north-up.
- Show course controls and route only when appropriate.
- Keep map legible on small screens.

### Course
- Generate 10 controls by default.
- Difficulty: Easy, Medium, Hard, Very Hard.
- Store generator seed/configuration.
- Validate control spacing and course sanity.
- Support manual control editing.

### Training
- Start countdown.
- GPS permission/status.
- Session timer.
- Current position.
- Current/next control.
- Mark control found.
- Finish session.
- Record GPS samples with timestamp and quality fields.

### Replay
- Play/pause.
- Timeline seek.
- 0.25x–8x playback.
- Follow-camera mode.
- Control-event markers.
- Route visualization.
- Jump to control/important event.

### Analysis
- Total time.
- Distance.
- Elevation gain where reliable.
- Controls found.
- Per-leg time.
- Per-leg distance.
- Route efficiency where a valid reference exists.
- Potential deviation flags with confidence/uncertainty.
- Time-loss estimates must be labeled as estimates.

### Progress
- Session history.
- Personal trends.
- Best/worst legs.
- Repeatable metrics.

## Future
- Memory-map mode.
- Route-choice exercises.
- Ghost runner.
- Adaptive training recommendations.
- Heart-rate import.
- Export/shareable replay video.
- Advanced field survey tools.
- Offline map packages.

## UX acceptance
A new user should understand the primary action on every screen within seconds without reading documentation.
