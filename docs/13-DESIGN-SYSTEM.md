# Design System

## Direction
Modern navigation instrument. Premium but restrained. The map is the hero.

## Layout
- mobile-first
- bottom navigation for primary sections
- full-screen map for active training
- desktop can use a side panel where it improves analysis
- avoid dense dashboard grids

## Color semantics
Use a consistent semantic system:
- primary action
- success
- warning
- error
- neutral
- map/control accent

Do not use color as the only semantic signal.

## Typography
Readable sans-serif. Strong hierarchy:
- page title
- primary metric
- section heading
- supporting label
- helper text

## Components
Build reusable:
- Button
- Segmented control
- Bottom navigation
- Map controls
- Training status
- Control marker
- Metric
- Timeline
- Analysis event
- Empty state
- Error state
- Permission prompt
- Confirm dialog

## Animation
Animations should communicate state or improve replay, not decorate the UI. Respect reduced-motion preferences.

## Outdoor usability
Large touch targets, high legibility, and minimal interaction during active training.
